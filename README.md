📝 Text Editor with Save Notes (LocalStorage)
A lightweight and responsive text editor that allows users to type, edit, and save multiple notes using localStorage. No backend needed!

🚀 Features
✍️ Real-time text editor

💾 Save notes with custom titles

📋 View all saved notes instantly

🗑️ Delete notes individually

📱 Fully responsive design (mobile-friendly)

⚡ Works offline using localStorage

📸 Screenshot

🔧 Tech Stack
* HTML5

* CSS3 (Bootstrap & Media Queries)

* JavaScript (Vanilla)

* FontAwesome Icons

* LocalStorage concept
